# Receptenboek
# =============
# Jullie complete verzameling recepten. Elk recept:
#   Gerecht: <naam>
#   Vlees: <kip/rund/varken/ei-vega/overig>   (voor het filteren op de website)
#   Label: <label>            (optioneel — zie labels hieronder)
#   Basispersonen: <2 of 4>   (optioneel, default 2 — het aantal personen
#                              waar de hoeveelheden hieronder al voor
#                              kloppen; bij een ander aantal personen
#                              schaalt de website/het script dit automatisch)
#   Tags: <tag, tag, ...>     (optioneel — vrije labels om op te filteren,
#                              zie de lijst hieronder; kip/rund/varken/
#                              ei-vega hoeven hier niet nog een keer bij,
#                              dat gebeurt al via Vlees:)
#   Actief: ja/nee            (optioneel — standaard "ja" als je niks invult)
#   gevolgd door ingrediënten (aantal x product)
# Lege regel = scheiding tussen recepten.
#
# LABELS die het systeem herkent (bepalen in welke pool een gerecht valt):
#   makkelijk     -> maandag (altijd 4 personen, snel, max ~20-25 minuten)
#   vrijdag_veel  -> vrijdag/zaterdag bij 4 personen (oneven weeknummer)
#   (geen label)  -> vrije "algemeen"-pool, gebruikt voor woensdag/donderdag
#                    (altijd 2 personen)
#
# TAGS die het systeem herkent (vrij te combineren):
#   snel, maandag, airfryer, rijst, pasta, wraps, bowl,
#   aardappel-vlees-groente, favoriet, nieuw, probeerrecept,
#   niet-meer-tonen, geen-vis
#   (kip/rund/varken/ei-vega zijn GEEN tags — die staan in Vlees:)
#   "nieuw" en "probeerrecept" worden automatisch gezet als je een gerecht
#   via de website toevoegt. "niet-meer-tonen" wordt automatisch gezet
#   zodra je een gerecht na het eten met "niet meer" beoordeelt — zo'n
#   gerecht wordt daarna nooit meer automatisch voorgesteld, ook niet als
#   Actief: ja blijft staan.
#
# ACTIEF: JA/NEE
#   Alleen recepten met Actief: ja (of geen Actief-regel) doen mee in de
#   automatische rotatie. Actief: nee betekent: staat in het boek om te
#   raadplegen of handmatig te kiezen (via naam typen bij het aanpassen
#   van een dag), maar wordt nooit automatisch voorgesteld.
